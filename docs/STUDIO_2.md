# Schizo Studio 2.0 — foundation

The first redesign replaces the simultaneously expanded category columns with a centered, viewport-aware workspace. Category navigation selects one real panel at a time; existing modules, settings, keybinds, presets and favorites are not replaced by simulated controls. Search matches module aliases, descriptions and setting names, and moves to a matching category when the selected category has no results. Ctrl+F or the top search field starts editing; Escape while editing clears search.

The named Schizo palette is now crimson/graphite. Existing named Schizo configurations using the previous lime accent migrate; custom palettes are preserved. The selected category rail uses a short eased transition with reduced-motion support. The loading overlay is a built-in geometric square-and-compasses emblem using the same accent.

This is the first foundation patch, not a claim that all Studio 2.0 features are complete. Dedicated inspector, undoable setting edits, conflict diagnostics, live previews, benchmark sessions/comparison, context profile editor, health dashboard, and desktop visual acceptance remain separate work. Real visual acceptance is required before a new release.
